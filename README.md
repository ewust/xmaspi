This code runs on a Raspberry PI and drives the [Bob and Betty Beyster Blinkenlights](https://docs.google.com/document/d/1kO2LvbGgDD-2SHmxqKJG2VrXhhx4hQG96N9LBkynDJc/edit?tab=t.0), a programmable light installation that consists of a pair of [GE Color Effects G-35 LED strands](https://web.archive.org/web/20190322170653/http://www.deepdarc.com/2010/11/27/hacking-christmas-lights/).
